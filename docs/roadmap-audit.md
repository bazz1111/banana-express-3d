# Blender + Three.js 路线核查

2026-10-13，基于当前工程与真实浏览器检查。图 A 仍是美术参考；可玩闭环通过不代表整图高保真验收通过。

| 阶段 | 当前实现 | 尚未实现／与路线的偏差 |
|---|---|---|
| 0 定方向 | 已选择 A；Vite、Three.js、Rapier、HTML/CSS；规则和物理使用严格 TypeScript；记录 60FPS／300 draw calls／30MB 目标 | 渲染和界面仍为 JavaScript；没有完整的描边、阴影色阶风格板 |
| 1 原型 | 装满 100 根、倒计时、2km 下坡、动态行人／羊／汽车／重卡、掉货、蓄力 Q、停稳交付；可调操控、跟随镜头、速度 FOV | 道路来自 Blender GLB 与积分曲线 JSON，未使用 CatmullRomCurve3；区块只控制实例可见性，未释放／流式加载资源；镜头采用指数插值；E 是稳货技能，尚非冲刺 |
| 2 Blender 资产 | 32 个本地 Blender GLB，两个可编辑 .blend；轮子／曲柄／肢体对象节点；20 捆货物矩阵；三种村落房屋、林冠树、石质基础；道路和水纹贴图打包导出 | 角色 5348 三角形，仍为程序化对象关节动画；无 Rigify、骨骼 Actions、三档 LOD、远景面片、烘焙 AO／间接光、Draco／Meshopt／KTX2 |
| 3 渲染 | 棱面 MeshStandardMaterial、动态阴影、雾、远景渲染通道、实例化与 GPU 植被摆动 | 无 Toon 明暗色阶、rim light、背面外扩／屏幕描边、Bloom／LUT／抗锯齿后期、径向模糊 |

| 5 UI 与系统 | HTML/CSS HUD、加载／出发／暂停／交货／结算／重开；技能冷却；本地最佳成绩 | 无在线排行榜与设置持久化；冷却显示沿用 A 的秒数胶囊 |

阶段顺序以可玩闭环优先，当前工作主要处于资产与画面完善。工程提前接入了部分 UI／特效／优化，不能因此认定后面阶段已完成。

## 本轮可核查的变化

山谷新增不同房屋和林冠树模板，调整湖岸地形、远山与森林层次。建筑按实际底层墙体和门廊占地设置石质基础，用实际湖面三角网格保留岸距，并排除建筑基础互相重叠。所有模型仍由本地 Blender 制作。

- 32 个 GLB 合计 5.78MB；构建静态目录约 12.62MB。
- Blender 检查道路坐标、贴地占地和建筑间距；实际 Three.js GLB 射线检查 120 座建筑的 1080 个采样点，以及三个指定湖面视线。
- 21 个规则／物理／镜头测试和类型检查、生产构建通过。
- 开发版完整键盘试玩：装满 100 根、交付 85 根、踢飞 2 辆车，暂停和重开通过，无浏览器／资源错误。
- 当前生产构建同样通过完整配送；5586 个下坡渲染帧的绘制调用峰值为 126，低于 300。欢迎场景在本机的真实帧间隔中位数约 16.7ms、p95 约 16.8ms。下坡使用加速测试时钟，绘制调用统计有效，不能用它证明真实帧率。

几何采样、HUD 布局检查、单机帧间隔测量均有各自范围，不能代替整图视觉一致性或指定中端设备验收。当前画面与 A 仍有明显差距，尤其是人物动作、车辆细节、连续林冠、光影和材质表现。

证据保存在 `artifacts/blender-valley-validation.log`、`landscape-report.json`、`fidelity-check.log`、`prototype-current.png`、`browser-check.log`、`production-browser-check.log`、`production-browser-report.json`、`valley-build.log`。
