# Banana Express 3D 全面重制与检查（2026-10-28）

本轮从 main `9f1689f` 在独立 worktree 实施。用户选定图A、无尽拾蕉、自由横移和可切换站姿；后续明确改用Tripo生成整套资产，因此本轮以 **Tripo H3.1 → 本地Blender精修/绑定/动作/LOD → Three.js集成** 为准。原工作区中其他游戏的改动没有纳入本轮。

## 可玩流程与规则

加载 → 准备 → 3秒倒计时 → 自动骑行 → 碰撞或主动结束 → 结算 → 重开。倒计时/骑行可暂停和继续，失焦或WebGL中断暂停。没有装货、终点、配送或100根通关判定。

## 动作、特效与渲染

AnimationMixer播放原生16Actions，接触IK读取同版自行车的掌心/鞋底/车座标记；默认坐姿，站姿、过渡、跳跃、双侧蓄力/踢击、倾斜、护盾受击和失败均有片段。快速C反向从当前姿态继续，蓄力预选即将进入射程的车辆，避免释放时换腿。暂停冻结动作、风、粒子、车轮及相机位置/朝向。

Three.js使用GLTFLoader+MeshoptDecoder、SkeletonUtils、InstancedMesh、共享原型、对象池、LOD、滚动区块和相对原点。首屏直接从已加载的作者道路取15类布景原型，取消相同模型的重复请求；只加载22个GLB。

基础色与UV保留，按是否存在COLOR_0启用顶点色，修复新主角变成黑色的问题。暖光、三层Toon、冷色环境光、雾、近景阴影、速度线和随速度变化的FOV统一画面；云使用明亮不受光材质。冲击星保留真实绘制纹理、正面朝镜头，小火花原生尺度与粒子参数匹配，不再用巨球挡住人物。

命中有顿帧、白闪、冲击星/光晕、碎石尘土、震动和分层声音。Rapier驱动重卡向前滚翻；最多12个、3秒寿命的装饰零件，采用真实中心枢轴及Y-up碰撞尺寸。回收模型前恢复脱落部件，旧碎片不再引用已复用车辆。声音加载/缓存、并发声部和缺样本回退沿用现有完整流程。

镜头依据真实人物/自行车/货堆/飞车范围取景，保留后侧角和两轮间距；镜头不得为了投影通过退入山体，也不能把人物缩成小点。同位置与道路边缘飞踢纳入单独回归。普通镜头纵向FOV不超过62°；极端竖屏为安全构图允许最高95°（390×844时横向约53.5°），持有必要视野后平滑恢复，不把纵向角度直接当成横向鱼眼程度。减少动态效果仍保留最小安全构图，关闭装饰性FOV脉冲/摆动；暂停保持相机及碎片严格冻结。

## 本轮修复的运行与工程问题

1. 高速一步跨越或横向离开跳障后漏奖：保存成功扫掠接触，在完全通过后只发一次奖励。
2. 新种子重开沿用相同编号但不同类型的旧模型：reset先恢复碎片，再把全部当前障碍回收到各类型池并清空映射；实际UI跨137→138回归确认barrier换成pedestrian。
3. 站姿reset首帧被默认为坐姿，导致立即Q时掌心误差：reset接收当前骑姿，初始化混合状态；默认普通重开仍坐姿。
4. 快速C切换和蓄力释放肢体跳变：统一上身/接触的混合时钟，重入切换不保留旧hold；Q复用目标筛选。
5. Banana/道具几何底部原点与逻辑拾取高度不一致：可见几何居中到实际拾取高度。
6. 卡车共享货箱中心及碰撞半尺寸轴序错误：逐共享几何居中，实例补回偏移，实际GLB/Rapier检验。
7. 主角黑色、冲击星侧向、火花过大：修正材质属性存在状态、原生朝向及尺度，以实景确认。
8. 复合道路的来源账本只列road-module：从真实GLB节点收集全部11类来源，账本与加载映射同步；门禁验证每类ID/SHA。
9. 原生CI可能覆盖手工源或跳过后仍放行：保存源只读重导，缺UV/动作及源写入拒绝；新增始终报告的asset-gate，失败/取消拒绝放行。

### 性能与加载的口径

首屏预算按 **实际HTTP编码资源传输** 计算，包含JavaScript、物理与GLB，不只数模型文件。22个运行GLB本身27.38MB；全部60规范导出49.98MB、无损Meshopt运行导出39.50MB。Brotli/gzip由生产服务器按浏览器能力传输，不改变模型精度。旧小资产版本的12MB冷启动门槛不再适用；本轮采用用户原定30MB预算，保留旧12MB失败记录，没有声称两者都通过。

所有帧时来自真实rAF完整窗口，未过滤长帧，含全部GL绘制与阴影通道。盾刷新仅用于测速不中断，明确不是自然玩家成绩。功能回归中的虚拟时钟只用来加快规则验证。真机为Apple M6；结果不替代GTX1650/IrisXe、手机或热降频验收。原始帧样本和长日志保留本机artifacts，仓库保存精简报告与代表实图。

### 场景支撑与像素检查的边界

原生8项检查全部通过。独立生产三角平面检查发现，5000m起点的Float32 BVH放置使源植物接触存在最大1.0364mm偏差；重复同一BVH只会测到6.1微米，不能替代真实三角验证。以4个5000m Float32高度ULP（1.953125mm）记录源数值界限，运行时另外严检新增支撑漂移≤0.1mm，实测最大0.0354mm；没有把源误差归零或伪称GPU漂移。轮胎道路间隙最大约0.0518mm，周期接缝/矩阵/地基支撑通过。

27个冻结距离×视口场景使用原蓝山像素门槛1.15%：**22/27通过，5/27未达**；全部桌面通过。4个medium、1个portrait失败集中在周期局部0–10m的视向，最小portrait百万米夹具为0.5484%。源实例、共享、精确距离和页面错误均通过。此项没有改门槛冒充通过，也不把模型数量当作整图还原；下一步应针对这些窄屏方向调整远景构图/局部轮廓。海湾与城镇的可读程度会随弯道变化，不能由一个像素比例证明严格图A高保真。
