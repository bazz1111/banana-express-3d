# 原型图高保真重建

本轮权威参考：`assets/reference/style-a.png`，原图 1672 × 941。用户最新明确要求“按照生成的图 a 作为标准”，沿用已选择的低多边形街机方向。保持所有三维模型在本地 Blender 制作，保留完整装货与交付玩法。

## 验收范围

- 顶部仅有香蕉、计时和速度黑色半透明圆角胶囊，白色粗体数字。
- 右下角有 Q/E 两个黑色技能胶囊、方框按键与秒数。
- 行驶画面没有品牌、白色信息卡、底部键盘说明、路线进度条或漫画爆字。
- 骑手红色短袖、深棕肤色、蓝色长裤、短卷发、黑白鞋；自然骑行与完全伸直的侧向飞踢。
- 黑色经典钢架自行车、细密辐条、银色挡泥板、载满成簇香蕉的后货架和绑绳。
- 灰色柏油盘山路、黄色中心线、白色路缘，右侧红土山壁、左侧香蕉摊与热带植物，石质护栏、山羊、行人、米色汽车、橄榄色篷布重卡。
- 密集热带植被、谷底红屋顶村落、蓝色湖水、分层山脉与白云。
- 近距离追尾构图：车轮接近画面下缘，骑手和香蕉占据画面中央前景，重卡在右上方倾斜起飞。
- 明亮的棱面模型、自然投影、右侧黄色飞踢爆闪、尘土与掉落香蕉。

## 执行顺序

1. 重建 HUD 和可重复的原型动作帧，核对几何布局与文字。
2. 在 Blender 重建骑手/自行车/香蕉/重卡的细节与关节，加入真实材质纹理和特效网格。
3. 重建红土山壁、热带植物、石栏、村落湖岸与远山，并匹配镜头与光照。
4. 逐次检查实际渲染与原型的差异，同时验证装货、避障、飞踢、交付、暂停和重开。

## 当前审计

旧版游戏的功能闭环已验证，但其白色 UI 卡片、粗糙低多边形人物、稀疏场景、锥形山峰和飞踢姿态与本次参考不一致。此前通过的功能测试不能证明当前高保真目标完成。目标保持 active，只有全部视觉及体验要求有当前证据时才能标记完成。
