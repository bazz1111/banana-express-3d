# 动态山路与节奏优化实施计划

> 执行方式：在当前隔离工作区内依次实施、验证，不重新制作已批准资产。

**目标：** 交通有可预判的运动、步态跟随真实位移、镜头连续过渡、飞踢更常用，并用小目标补充无尽循环。
**架构：** game.ts 唯一拥有障碍移动、计分与任务状态；表现模块读取速度/路程驱动姿态。保留扫掠碰撞、固定60Hz、自由转向和原有资源池。
**技术：** 现有 TypeScript / Three.js / Rapier / Blender 导出资产；不新增依赖或付费生成。
**基准：** main 8443911，用户认可的当前美术、无尽模式与输入；本次已授权实现。

## 设计与取舍

- 正常车辆增加低速行驶；只在玩家接近后唤醒，避免远处预加载车辆跨区拥挤。动物/行人使用局部一次横穿，先朝向目标再起步；静态障碍保持静止。碰撞和画面使用同一个位置。
- 步态相位依路程、振幅依速度，停止归于站立；山羊四拍步态，保留原生比例和枢轴。姿态更新不能改变碰撞坐标。
- 删除换侧/飞踢时直接复制相机的跳变；独立连续跟随位置、目标和FOV，飞踢蓄力时提前构图。保留道路内取景和竖屏安全画幅，暂停冻结，重开初始化一次。
- Q 命中和挥空统一8秒冷却、卡车仍需蓄力0.8秒、单次仅踢一辆，不给无敌和冷却返还。6秒E冲刺不变。
- 补充循环目标：收集12根香蕉（150分）→安全通过6个障碍（200分）→完成3次跳障/踢车/险避（250分），循环但不递增奖励。不以任务失败结束骑行。每个事件只计当前目标一次；任务分不乘连击/双倍、不触发下一任务的进度。
- 玩法复验补充：连续按左/右原本均可无操作到8000m；从344m起每480m交替布置一次路肩高墙，中心通路保留，追加高速度路线搜索。
- 险避：障碍纵向接触期间横向净距0.08–0.40m、地面通过、无碰撞/护盾免疫，每个障碍通过后仅奖励25基础分；正常安全绕行仍有目标进度，不逼迫冒险。

## 关注边界

1. 后加载障碍不能用全局elapsed跳位置；进出区块运动与计分不重复。
2. 高速动态相向碰撞、横穿和香蕉路径不能留下未测死路。
3. 竖屏飞踢过渡可读性与平滑性一起验证；静态拟合通过不代表连续镜头通过。
4. 暂停/失焦/取消/新局不能残留动画、任务奖励或冷却。
5. 自动化能证明规则和连续性；真人趣味性、实体手机和中端显卡仍需实测。
