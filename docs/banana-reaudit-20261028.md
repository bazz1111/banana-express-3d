# Banana Express 3D 技能复审与修复

依据更新后的本地game-development技能，复审现有架构、玩法、关卡及性能。基线为PR #4的 `ae954381075cef195dd56837f31bd425c8eac098`，在 `codex/banana-comprehensive-20261028` 修复。保留已认可的Tripo/Blender画面、无尽拾蕉、自由横移和技能数值，本轮没有生成新资产或消耗积分。资产与动作专项仍引用[资产重制报告](banana-audit-20261028.md)，不把旧测量写成本轮新结果。

## 架构结论与改动

现有约2300行运行代码，采用普通模块已能分清状态和生命周期。继续使用Vite、Three.js和Rapier，不增加ECS、React、全局事件总线或依赖。

| 责任 | 当前实现与本轮核查 |
|---|---|
| 规则权威 | `game.ts`唯一决定移动、碰撞、奖励、冷却和结束；60Hz固定步进，单次delta最多追赶0.25秒。动画/物理碎片不发分数 |
| 输入到规则 | `main.js`收键盘/触控；新增25行 `ActionBuffer`保存跨帧按下意图，实际模拟消费后清除。`advance`返回步数，一次性命令只送首个追赶tick |
| 表现/物理 | `view.js`读取状态和规则事件，Mixer/IK负责人物、Rapier负责飞车/装饰零件；现有池和共享资源保留 |
| 本局与应用生命周期 | 重开重建GameState、清输入与表现，复用渲染器/共享资产；跨种子异类型回收、失焦/上下文恢复和存储容错沿用现有回归 |
| 内容/配置与持久化 | 障碍尺寸和种子保留在规则定义；会话/画质/声音和本机纪录独立保存，不把Three.js对象写入存档 |
| 暂停渲染 | 首次paused帧后不再提交相同3D场景；resize、画质和上下文恢复使缓存失效；DOM菜单持续响应 |
| 首用渲染准备 | 加载期覆盖高/低档前景和远景的真实阴影配置；1像素画布实际绘制以完成首次shader日志、uniform及纹理使用，然后恢复全部显示/裁剪/画布状态 |

修复前输入只在每帧查询“当前是否按住”，按下与松开都发生在两个渲染帧之间就会丢动作。现在区分持续状态与物理按下；快速再按不会被上一tick的held吞掉。普通Q松手仍释放蓄力；pointercancel/lostpointercapture只在最后一个输入源取消时清蓄力，不能错误消耗18秒冷却，也不能抹掉仍按住的键盘源。

静态类型覆盖范围仍是 `src/**/*.ts`，不声称JavaScript表现层已全面类型检查。已有运行边界与实际输入测试约束本轮修改；未为覆盖数字迁移整套JS。

## 发现的问题与实际修复

| 问题/责任层 | 修复前证据 | 修复与回归 |
|---|---|---|
| 短按Space/E消失／输入 | 实际键盘按下松开置于0模拟时间窗口后，跳高0、boost0 | 缓冲至下一模拟tick；浏览器跳高0.7183m、boost1.3833秒；模拟测试覆盖无tick帧和只触发一次 |
| 快速第二次按下被held吞掉／规则边沿 | 上次held为true但本次tick前已松开再按，动作未触发 | 显式jumpPressed/dashPressed，追赶多个tick也只使用首个边沿 |
| 触控取消变成踢击／输入源 | 普通删除pointer会被当作Q松手；另有取消触摸与键盘同帧松开的竞态 | 事件当时判断是否还有源；真实CDP touchCancel和键盘混合回归，取消不花冷却，合法松手仍踢 |
| 点画质后Space继续切画质／DOM焦点 | 操作后焦点quality，Space使low变high | 游戏进行时画质/音效操作返回画布；菜单暂停保留原生焦点与操作语义 |
| 暂停仍全速绘制／渲染 | 未改变场景，等5个rAF仍增加1164次GL调用 | paused按需重绘；三尺寸实测相同窗口0次新增GL调用，resize仍重画，时间不推进 |
| 慢速CI触屏检查失败／测试夹具 | ae954的Chromium远端日志：执行控制检查期间自然障碍已结束本局，触控按钮消失 | 自然开局30m后显式进入空路输入夹具；保留真实输入及暂存卡车，失败保存状态/截图，不将夹具当自然成绩 |
| 首次踢车卡顿／加载与渲染 | 本轮初次60秒采样：高档首击最长55.5ms、低档94.3ms；CPU诊断指向shader/program日志和参数查询，低档首击新增3个basic变体 | 预热两档四种前景/远景配置和未来障碍；compileAsync后在默认framebuffer做1像素首次绘制，再恢复完整画布。未关闭shader错误检查，实际首击帧时另测 |
| 关卡检查只看局部宽度／验收不足 | 每个障碍留空不等于连续转向可到达 | 新增路径搜索与生产碰撞重放，CI保留种子、入口和输入序列 |

输入问题先记录失败，再修复与回归。独立只读审查发现的物理边沿、多源取消和路径初始化辅助状态污染，以及“一个无效入口中止全部入口”也分别加入失败/通过测试。最终静态复核确认这些指定问题已关闭；浏览器、性能结果由实际运行另证。

Shader预热也核查本项目锁定版本的Three.js实现：低档是关闭shadowMap渲染但保留sun.castShadow，不能用远景的sun.castShadow=false替代；compileAsync只等编译ready，首次日志/uniform查询仍延迟。加载期首次draw采用独立相机启用两层，覆盖四种阴影组合；原远景相机只绘制layer1，会漏掉已编译的前景冲击星。预热临时演员共享原几何/材质，仅移除，不dispose运行资源；finally恢复可见性、裁剪、阴影和当前尺寸。冒烟检查尺寸恢复、0新增色彩program及0次监测的首次shader日志/uniform/attrib查询，真实帧时仍另外采样。

## 玩法与关卡核查

完整流程仍为加载→准备→倒计时→自动骑行→暂停/继续→碰撞或主动结束→结算→重开。12m/s起步、每250m加1、基础上限26m/s，加速最高32.5m/s；Q、E、跳跃、坐站切换、三道具、连击和持久化规则未改。已有测试覆盖扫掠横穿/薄障碍、成功跳越只奖一次、先拾取护盾后碰撞、结束后不再计时发奖和重开清理。

80m确定性区块、480m前视、后方约80m回收、8个近景槽和1600m地形周期保留。首两段教学种子固定，160m后随本局种子变化。没有把模板摆放点改成三轨限制。

`pnpm check:course` 检查12个种子×0/4000/1000000m，共36个12秒窗口。搜索每0.1秒选择左/直/右，最多128候选，再使用正式60Hz移动/碰撞精确重放。每步排除拾取、护盾、无敌、踢车，不跳跃；加速buff作为压力夹具，晚段达到32.5m/s。初段从中间进入，高里程从-2.4/0/2.4m候选入口选一条，记录实际入口和全部输入；初始elapsed与横向速度为0，没有继承自然前序的动态相位。

36组通过。该结果是有限采样存在性证据：搜索可能漏掉有效路线，也不证明所有种子、任意前序车位连通或真人反应足够。种子65535的4000m强制中心传送已接近长车头，失败不能当作自然前序路径必撞；保留中心失败及侧方成功的回归。全路封墙、出生盾污染和不安全候选入口都有拒绝测试。本轮没有足够证据表明生成器本身存在必撞布局，因此没有任意重排节奏或降低障碍难度。

长期内容仍复用1600m地标；更丰富区域及真人难度曲线属于后续内容迭代，不由自动搜索宣称已解决。

## 本轮验证与性能

- 基线149项测试通过；本轮增加9项输入、5项路径回归，最终 **163/163通过**，0跳过。
- 生产构建、TypeScript检查、60资产验证、无损压缩和62文件严格指纹通过；没有修改Blender/GLB，未重复进行整套资产生成。
- Chrome156/Apple M6的1280×720、390×844、360×780高档实际键盘/持续触控检查通过。含快速按下松开、画布焦点、Q命中、触控取消、暂停0绘制及resize。
- 低档强制SwiftShader的960×540和390×844同样通过，包含真实持续触控/取消；功能夹具隔离不依赖GPU速度。三尺寸高档及软件低档的首击0新增色彩program、0次监测的shader日志/uniform/attrib首次查询，加载后尺寸恢复通过。
- 最终生产构建再次通过键盘自动游玩：3602.925m、自然158蕉/3辆卡车、三道具、跳跃、坐站、E达到32.5m/s、暂停、主动与碰撞结束、重开；0页面/资源错误。8个模型、5个车辆刚体是该跑局的观察峰值，不当作全局上限。虚拟时钟只加快功能检查，不用来报告FPS。
- 实际WebGL丢失/恢复后仍暂停、显式继续后运动恢复通过；暂停缓存未阻止恢复重绘。该项使用虚拟时钟验功能。
- 浏览器截图和报告使用明确的空交通/85蕉/临时卡车/时间冻结夹具；它们证明输入/展示/状态链，不证明自然成绩或FPS。

本轮持续性能使用Apple M6、Chrome156/Metal、1920×1080、DPR1、有头窗口；每档预热5秒后各采样一次完整60秒，最高速/100蕉/6次真实Q。护盾刷新、3750m起点、空交通和冷却重置是压力夹具，无虚拟时钟。保留全部rAF及长帧、全部GL绘制和阴影通道，GPU任务顺序执行。

## 剩余边界

可用机器是Apple M6，不代替GTX1650/IrisXe或手机实体设备。Firefox若WebGL2不可用要记录跳过，不能算浏览器兼容通过。原视觉的五个窄屏蓝山面积、四个极端人物屏占例外和车轮局部UV接缝沿用[卡点记录](BLOCKERS.md)；本轮没有通过改截图门槛或重生成模型掩盖它们。JavaScript全面静态类型、联网排行、KTX2和完整lightmap均未新增。没有新联网产品目标，不扩大为服务端开发。
