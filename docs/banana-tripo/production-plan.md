## 一次确定的生产顺序

1. **统一参考。** 共29类，每类完整独立轮廓、浅灰背景、暖色手绘卡通材质；成人主角红衬衣/蓝裤、黑色二八自行车、金黄大香蕉、橄榄卡其卡车。保留原图、提示词和哈希。
2. **三维母版。** 先验证主角和自行车确实能以H3.1生成、8K导出，再批量制作27类。只提交一次生成；技术处理失败先修输入或网格，不无目的重抽模型。
3. **并行机械工序。** 植被、岩石、建筑、障碍和道具采用同一Blender配方规范尺寸、原点、材质、减面和贴图。共享母版派生LOD与有依据的比例/色彩变化，减少重复工作。
4. **优先精修主体。** 主角绑定/权重、车轮/曲柄、手脚接触点、香蕉货架净空、卡车拆分与翻滚。自动生成的通用动画不作为骑车验收依据。
5. **场景整合。** 道路连续可驾驶，近景红岩和棕榈、低护栏、白墙红瓦城镇、蓝色海湾和层叠远山统一构图。远景用低模和实例，避免生成景物遮住海湾。
6. **运行验收。** 所有可见资产有新来源映射；检查贴图、轴向、比例、穿模、碰撞和玩法；完整构建后实测加载、内存、绘制调用及帧率。最终截图来自实际可玩版本。

## 游戏资产规格与质量要求

| 类别 | 运行三角面目标 | 运行贴图目标 | 必须检查 |
| --- | --- | --- | --- |
| 主角 | 20k–30k | BaseColor 2K；近景必要时4K | 面部与服装轮廓、连续皮肤、骨骼权重，坐/站/跳/左右踢无严重穿模 |
| 自行车 | 12k–24k | 2K | 经典横梁、细车轮负形、独立轮轴/曲柄、车座和车把接触位置；源轮与叉/链罩融合处在本地用真实无遮挡轮扇区修复 |
| 蕉束 / 单蕉 | 1k–3k / 400–900 | 1K / 512 | 饱满弯曲形体、共用果柄、深色果尖；20束货架使用实例化 |
| 卡车 / 普通车 | 15k–30k / 6k–10k | 2K / 1K | 宽高与碰撞代理相符，卡车分件枢轴、踢飞后完整可读；完整预算包含新增可脱落货箱 |
| 行人 / 山羊 | 6k–12k / 3k–6k | 1K | 不与主角竞争细节，腿部/角/四肢不粘连；如需移动动作，保留关节 |
| 障碍 / 道具 | 500–4k | 512–1K | 低障可跳、高墙/长车必须躲，图标负形与颜色远处可识别 |
| 植被 / 岩石 | 近景300–2k，远景12–200 | 512–1K | 叶片负形、树冠轮廓、岩面层次，实例化与LOD；不是把高模复制数千份 |
| 建筑 / 路牌 / 护栏 | 500–4k | 512–1K | 门窗与棚下开放空间、落地支撑、红瓦白墙和黑黄弯道牌 |
| 山体 / 岩壁 / 道路 | 每个模块2k–12k，远景按可见预算 | 1K–2K | 道路拼缝/车轮支撑、坡度与地形一致；保留海湾和聚落视线 |
| 云 / 冲击星 | 低面轮廓或图集 | 256–1K | 与场景一致，避免遮住障碍；强闪和镜头震动受减少动态设置控制 |

8K是只读母版质量，不是所有运行模型的贴图分辨率。运行时按屏幕占比缩小贴图并压缩GLB，采用Three.js实例化、LOD与有限近景阴影。中端电脑目标60fps、绘制调用300以内、首屏资源30MB以内；实际结果与尚未测试的硬件分别记录。

用户已明确选择后续采用“主体、复杂环境、简单远景分三档”。继续统一H3.1：主体默认超清几何+4K、按材质需要PBR；复杂环境超清几何+2K基础色；简单远景常规几何+2K基础色。这29类按同样规格重新估价为6×55＋12×40＋11×25＝1,085积分，仅供未来同等资产量预算；本轮不重生成。类别与未来预算记录在源manifest.productionTier，运行资产继续有独立面数、贴图和LOD预算。本轮27项已经提交，改成低档重新生成不会追回已消耗积分，反而增加支出。现在执行导出、本地优化、绑定适配与集成，不新增Tripo付费操作。遇到必须重新生成或服务处理的缺陷，先列出缺陷证据与单项报价，再决定是否有必要。

其他省时方式：从合格母版派生岩石旋转/比例、树冠/树干色彩、建筑长宽/屋顶变体；图像只修确有问题的参考；静态减面、LOD、贴图缩放与标准动作在本地Blender批处理。不会为每个LOD或颜色变体单独付费生成。更换低档模型或其他平台不能自动改善风格，且会引入新的订阅、导入和材质适配成本。

## 避免返工的准入规则

- 每项记录 reference → Tripo任务URL/所选模型/实际扣费 → 源文件SHA256 → Blender源 → GLB/LOD → 实际运行截图与检查结果。
- 自动生成不是自动合格：自行车辐条空隙、香蕉果柄、人物手指/关节、棚顶空隙、叶片和“×2”形状必须逐类检查。
- 不因生成高面数就重新生成低质量版本；保存高模，从同一母版派生游戏低模。
- 修改范围和源模型有据可追；旧隐藏碰撞代理可保留，旧可见几何不能冒充已重制的Tripo资产。
- 模型、绑定、网格优化和实际游戏验收分开记录；不会把二维参考完成计作三维集成完成。

- 复杂环境：pedestrian、goat、barrier、crate、wall、train、palm、banana-plant、hut、stall、cliff、road-module。
