# Banana Express 3D：动态山路、动画与玩法节奏

基线是 main `8443911`。本轮在 `codex/banana-living-road-20261030` 保留已认可的 Tripo/Blender 资产和无尽自由转向玩法，修改规则、表现、HUD与验证脚本；没有重新生成模型或消耗积分。当前运行入口为 `http://127.0.0.1:4183/?seed=2817`，可复现启动方式见README。

## 复盘与实现

| 观察与责任层 | 原因 | 实际改动 |
|---|---|---|
| 车流像路障一样静止 | 生成器没有配置车辆速度 | 前方60m唤醒：汽车逆向2.5m/s、卡车同向1.6m/s、长车厢逆向1m/s。保留静态墙/箱/栏，不让所有障碍无差别运动 |
| 行人/动物突然换位或掉头 | 横穿使用全局elapsed正弦；新实体初始化相位不对应全局时间，往复端点直接转180° | 每个实体维护局部时钟，4秒内平滑横穿2.1m后停止；非横穿步行者以0.55m/s前行。方向、位移、规则碰撞同源 |
| 动物原地踏步、脚步不随速度 | 按渲染时间统一摆腿，甚至静止实体也播放；原山羊同侧前后腿同相位 | 路程决定步态相位、实际速度决定振幅；山羊四拍、行人对侧交替，静止归于原姿态。缓存原生枢轴和脚底点，补偿轻微地面穿插，池化重用时复位 |
| 横穿山羊侧身可见尺寸与碰撞不一致 | 仍使用朝前的窄AABB | 将长/宽按规则朝向投影，扫掠碰撞和险避共用相同尺寸；增加真实边缘回归 |
| 换侧/飞踢时视角跳变 | 换侧和命中时直接copy位置/目标，FOV直接赋值 | CameraFollow统一过渡，位置≤12m/s、角速度≤1.8rad/s、FOV≤60°/s；只在初始化/新局设位，震动不累积进基础姿态 |
| 平滑后竖屏飞车短暂裁边 | 相机滞后于翻滚车辆 | 蓄力期提前构图；以质心、线速度和角速度预测180ms的轮廓，连同当前轮廓一起拟合。保留既有完整入镜检查，不放宽裁边阈值 |
| Q机会间隔过长 | 18秒相当于约216–468m基础行程 | 改为8秒（约96–208m）；仍需0.8秒蓄力踢卡车、每次最多一辆、挥空同冷却、不授予无敌或返还冷却。E保持1.5秒冲刺/6秒冷却 |
| 一直贴边就能跳过整个玩法 | 种子2817中持续按左/右，两侧均无判断骑到8000m | 从344m起每480m布置一次交替左右的路肩高墙，中心留空；两边都不能永久躺赢。保留最初160m教学和自由转向，追加路线搜索与5种子双侧挂机失败回归 |
| 长期循环缺少短目标，绕行反馈弱 | 主要关注累计距离和香蕉，安全路径与小风险差异反馈有限 | 新增收集12蕉→安全通过6障碍→3次跳障/踢车/险避的循环目标，固定奖励150/200/250分；贴边险避25基础分并续连击。HUD持续展示当前目标/进度，结算展示目标数与险避数 |

任务奖励不乘连击/双倍，不反馈冷却，同一动作不顺带推进下一个目标。险避只在完全通过后发一次，横向净距0.08–0.40m；跳跃、踢走、护盾、免疫或碰撞期间不能刷险避。未完成任务不结束骑行。目标是在保留简单操作的前提下增加收集、稳妥通过和冒险特技的选择；自动化验证这些规则，不代表已经证明真人留存提升。

独立只读评审发现并关闭两项问题：原生卡车后轮包含双轴轮胎，整体旋转会穿地；矮屏目标栏与计分/道具栏重叠。进一步检查发现前轮也有偏心几何，因此全部卡车轮组保留作者原姿态，车辆整体运动；不以错误旋转制造动感。另修正竖屏“走你！”文字断行。
